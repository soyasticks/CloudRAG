# Sample Documents

This folder is where your sample policy PDFs go for local testing and for
uploading to the deployed app. No real PDFs are included in this repo —
you'll need to add your own (or generate simple placeholder ones) named
to match `evaluation/test_questions.json`:

- `Employee Handbook.pdf`
- `Leave Policy.pdf`
- `IT Security Policy.pdf`
- `Reimbursement Policy.pdf`

## Generating placeholder PDFs quickly

If you don't have real policy documents handy, you can write a few pages
of plausible-sounding policy text yourself (e.g. in Google Docs) covering
topics like leave entitlement, remote work, password requirements, and
expense limits, then export to PDF. Keep the content simple — 2-4 pages
per document is plenty for this project and keeps ingestion/eval fast
and cheap.

Do not upload real, sensitive, or confidential company documents to a
personal AWS account for a portfolio project.
